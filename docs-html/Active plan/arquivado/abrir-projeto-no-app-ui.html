🎨 Protótipo · "Abrir projeto" no card do manager

Hoje o botão ⌨ Warp abre a pasta da docs (ex.: projeto-x\docs). O objetivo: abrir a pasta do projeto (o pai da docs, ex.: projeto-x) no Warp, deixando claro o nome da pasta da docs. Quatro variações — clique nos botões dos cards para sentir o fluxo. Prós e contras no fim de cada uma.

A — Dois botões explícitos no card

+ máxima clareza: cada botão diz exatamente o que abre; zero ambiguidade · − mais um botão em TODOS os cards; o caso raro (abrir a docs em si) ocupa tanto espaço quanto o comum
