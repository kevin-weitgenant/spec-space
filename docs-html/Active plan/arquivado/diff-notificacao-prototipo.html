Visão geral

A feature Foo faz X e Y, com os trade-offs discutidos em reunião. O documento segue a mesma estrutura dos outros planos: contexto, decisões e riscos.

Decisão técnica

Usar polling de 5s para atualizar a lista de itens. O polling é simples de implementar e não exige infraestrutura nova, mas adiciona latência perceptível.

Arquitetura

O cliente consulta /api/items a cada 5 segundos e re-renderiza a lista inteira. Não há estado no servidor além do próprio banco.

setInterval(fetchItems, 5000);
function fetchItems(){
  fetch('/api/items').then(r => r.json()).then(render);
}

Escopo da v1

A v1 entrega a lista com atualização automática, ordenação por data e indicador de item novo. Filtros ficam para a v2.

Abertos

Nada por enquanto.

Cronograma

Duas semanas de implementação, uma de polimento e testes. Review contínua com o time de design.

Alternativas consideradas

WebSocket foi descartado pela complexidade de infra; long-polling por inconsistências de comportamento entre browsers.
