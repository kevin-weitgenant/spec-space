AJourney map — a features como narrativa de uso

Você lê em ordem, como uma receita. Cada passo carrega só as features daquele momento; nada de catalogue para decorar.

  1. Aponte pra uma pasta

    spec-space ./minhas-docs — escolhe porta livre sozinho e registra no manager.

    porta com fallback_config.json auto

  2. Abra no browser

    A shell nasce com sidebar em árvore das suas pastas — sem build, sem config.

    sidebar automáticatítulos por aba

  3. Edite sem sair da página

    Ctrl+E liga o WYSIWYG; Ctrl+S salva no arquivo. A página recarrega sozinha.

    editor inlinehot reload

  4. Volte amanhã e veja o que mudou

    Blocos novos ganham chip verde, editados ganham word-diff âmbar; minimapa lateral pula direto pra mudança.

    change highlightsminimap

  5. Diagramas legíveis

    Mermaid e SVGs ganham pan/zoom + lightbox automaticamente.

    mermaid-zoom

  6. Muitas pastas? Um manager.

    Todos os projetos num mural único, cada um no seu prefixo /slug/.

    managermural

  7. Publique

    spec-space export congela tudo em arquivos estáticos — Netlify Drop, Pages, Surge.

    export estático

Sensação: conto uma história; o leitor sai sabendo USAR, não só listando. Custo: as 34 features precisam se encaixar nos passos (algumas são "detalhe do passo N").

CCards enxutos — uma frase + profundidade sob demanda

Cada card colapsado mostra só ícone + nome + uma frase. O detalhe mora dentro do <details>, aberto só por curiosidade.

🔄Hot reload— recarrega só o que mudou · sem botão
Um único SSE por browser (eleição via Web Locks + BroadcastChannel). Cada aba filtra os eventos do seu próprio root. Recarrega a página se o arquivo DELA mudou; assets compartilhados (.js/.css) recarregam qualquer doc.
✏️Editor inline— WYSIWYG · Ctrl+E / Ctrl+S
Liga contenteditable no body, preserva <pre> como texto puro, e ao salvar remove tudo que o dev-server injetou (data-injected) antes de escrever no disco via /__save__.
✨Change highlights— chips "novo" + word-diff + minimap
Compara o texto da página com um snapshot no localStorage da sua última visita (LCS puro em diff.js). A chave do snapshot sobrevive a deploys — seu histórico não zera.
🗂️Sidebar em árvore— nasce das pastas · menu ⋯ · contexto
Manifest da pasta vira árvore; arrastar reordena (persiste via /__order__), menu ⋯ copia caminho/revela/move, clique direito cria pasta. Ícones Lucide ou emoji via _config.json.
Sensação: a página fica curta e silenciosa; o peso só aparece quando você pede. Custo: recursos "escondidos" — quem não abre o details não descobre nada.

Combinação natural
A para a espinha dorsal (a jornada) + C para o corpo de cada passo (frase curta, details sob demanda). A tabela B pode fechar como "índice completo" no fim. D e E são boas ideias para o manager UI, não para um doc.
Como escolher
Pense em quem vai abrir: alguém conhecendo o projeto pela primeira vez → A (ou A+C). Você mesmo daqui a um mês procurando "aquela feature do menu ⋯" → B ou D. Quem decide em 10 segundos se vale a pena → E no topo, resto embaixo.
